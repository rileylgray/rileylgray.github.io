What's inside

Everyone on their own phone

No TV, console or extra screen. Play in the same room or miles apart on a video call — iPhone and Android players join the same rooms.

No sign-up

No account needed. Pick a name and an avatar, then create or join a room with a six-digit code.

Host picks or everyone votes

The host chooses who decides the next game and how many people can join, from 2 up to 12. Points carry over from game to game.

Bots fill the seats

Short on players? Bots jump in so small groups can play every game. Practice with Bots runs a whole room on one phone, offline.

Share the code

Send the room code and the download links by text or any chat app in one tap.

Kept friendly

A word filter on names and answers, house rules on first launch. Tap a player to report them, and hosts can remove players.

How a room works

  1. The host makes a room and picks the settings: host picks or group vote, max players, and whether bots fill empty seats.
  2. Friends join with the six-digit room code.
  3. Everyone taps Ready. The host can add or remove bots.
  4. Pick the next game. The host chooses, or the room has 30 seconds to vote.
  5. Play, laugh, rematch. Scores add up across games, then it's back to the list.

Online rooms need an internet connection, and each player needs the app on their own device. Questions, ideas or need a hand? Email realgamesrealfun@outlook.com.
